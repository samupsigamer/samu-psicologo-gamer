# Samu Psicólogo — Web 2026 integrada

Versión integrada del modelo web 3 con la arquitectura Web 2030.

## Diseño
- Base visual: modelo web 3: fondo oscuro, morado/neón, estética gaming limpia.
- Chibi: reservado para hero/ilustraciones, recursos, familias, gaming, explicaciones y CTA.
- Profesional: Sobre mí, UX e investigación usan una composición más limpia y sobria.
- Responsive y sin dependencias externas.

## Estructura
- `index.html`
- `pages/`
- `css/styles.css`
- `js/main.js`
- `data/resources.js`
- `assets/img/`

## GitHub Pages
Sube el contenido del ZIP al repositorio y activa GitHub Pages desde Settings → Pages → Deploy from branch → main → root.
